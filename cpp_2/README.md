# Умные указатели

### `unique_ptr`

Используется для владения объектом до прохождения техосмотра.

Если объект не проходит техосмотр, он должен быть уничтожен. Ничто не должно продлевать время его жизни.

### `shared_ptr`

Используется для хранения объектов в векторе парка.

Позволяет создавать `weak_ptr`, которые могут наблюдать за объектами парка. Это необходимо для реализации витрины.

### `weak_ptr`

Используется для хранения указателя на объект парка, выбранный командой `focus`.

Удаление объекта через `remove` не должно зависеть от витрины. `weak_ptr` не продлевает время жизни объекта и позволяет определить, был ли он удалён.

# Исключения

В программе предусмотрены следующие исключения:

1. `RejectedInspectionError` — объект не прошёл техосмотр.
    
2. `DuplicatedIdError` — объект с таким ID уже существует в парке (при попытке добавления).
    
3. `IdNotFoundError` — объект с таким ID не найден (при попытке удаления или выбора объекта).
    
4. `InvalidArgumentError` — некорректные аргументы: отрицательная или слишком большая энергия, простота использования вне диапазона 1–10, неизвестный тип предмета.
    
5. `CommandNotFoundError` — неизвестная команда.
    
6. `WrongArgumentsNumberError` — неправильное количество аргументов.
    
7. `WrongArgumentTypeError` — неправильный тип аргумента (например, текст вместо числового значения энергии или простоты использования).

# Шаблоны

### `ValidatedValue`

Шаблонный класс, который хранит значение и при создании проверяет его на принадлежность заданному диапазону.

Используется в классах `EnergyConsumer` и `Vehicle`.

### `Fleet::AddItem`

Шаблонный метод, который сокращает количество кода, позволяя добавлять все виды предметов через одну функцию.

### `CommandHandler::ParseNumericType`

Шаблонный метод, который преобразует строку в `int` или `double`.

# Правило техосмотра

Все предметы, не являющиеся транспортными средствами, всегда проходят техосмотр.

Транспортные средства не проходят техосмотр с вероятностью **30%**.

Я выбрал вероятностный подход, поскольку он показался мне более реалистичным: результат техосмотра заранее неизвестен.

# Перегрузка операторов

- `operator<<` — вывод описания предмета.
- `operator<` — сравнение предметов по ID.
- `operator==` — проверка равенства ID.
